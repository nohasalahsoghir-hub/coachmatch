# CoachMatch 🥊⚽🎾

منصة ثنائية الاتجاه تربط المدربين الرياضيين المعتمدين بالمتدربين في مصر.

## المميزات

1. **اكتشاف المدربين:** 30 رياضة، بحث وفلترة حسب الرياضة والمنطقة والسعر والمواعيد المتاحة فعليًا اليوم.
2. **ملف المدرب:** بيانات عامة آمنة، تقييمات حقيقية، أماكن التدريب، والجدول المتاح للحجز.
3. **الحجز المباشر:** اختيار اليوم والساعة والمكان ثم تأكيد الحجز مباشرة داخل قاعدة البيانات، مع حماية من التعارض والضغط المكرر.
4. **الباقات:** تفعيل باقة 8 حصص تجريبية، ثم استخدام حصة واحدة لكل حجز مع منع الخصم المزدوج.
5. **لوحات مخصصة:** لوحة المتدرب، لوحة المدرب، ولوحة الإدارة للتوثيق والنزاعات.
6. **التجربة الآمنة:** البيانات العامة منفصلة عن بيانات المدرب الداخلية، ولا توجد بوابة دفع أو تحويلات مالية فعلية حاليًا.

## البنية التقنية

- **Frontend:** Next.js 15 App Router + React 19 + Tailwind CSS.
- **Backend:** Supabase PostgreSQL + RLS + Server Actions.
- **Public data:** `coach_public_catalog` وواجهات عامة مخصصة للمواعيد المتاحة.
- **Booking integrity:** قيود PostgreSQL، أقفال الصفوف، ومفاتيح منع التكرار.

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتحي `http://localhost:3001`.

المتغيرات المطلوبة في `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://<project-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
SUPABASE_SERVICE_ROLE_KEY=eyJ...
```

## التحقق

```bash
npm run build
npx tsc --noEmit
node scripts/verify-product-v3.mjs
```
